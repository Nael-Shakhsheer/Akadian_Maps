# Johnson Center — Sources

Downloaded 2026-10-23 from GMU's public Student Centers site: https://studentcenters.gmu.edu/the-johnson-center

## Architectural room plans (`source/floor-plans-pdf/`)

| File | Original URL |
|---|---|
| JC-Ground-Floor-Plan.pdf | https://studentcenters.gmu.edu/wp-content/uploads/2020/11/JC-Ground-Floor-Plan.pdf |
| JC-First-Floor-Plan.pdf | https://studentcenters.gmu.edu/wp-content/uploads/2020/11/JC-First-Floor-Plan.pdf |
| JC-Second-Floor-Plan.pdf | https://studentcenters.gmu.edu/wp-content/uploads/2020/11/JC-Second-Floor-Plan.pdf |
| JC-Third-Floor-Plan.pdf | https://studentcenters.gmu.edu/wp-content/uploads/2020/11/JC-Third-Floor-Plan.pdf |

- Generated by GMU's space-management system ("Architectural Rooms for Floor: 0077: JOHNSON CENTER-N"). Building number is **0077**.
- Every room is labeled with its number, plus CORR (corridors), STAIR, ELEV, VEST (entrance vestibules), MENS/WOMENS, SHAFT, JAN etc.
- The plan is an embedded image, not vector data, so tracing has to be done visually (the text can't be extracted).
- Dated 2020; check against the 2023 directories for changes.
- The Event Services copies (es.gmu.edu) are byte-identical, so they weren't kept.
